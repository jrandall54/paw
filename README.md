# The Pedagogical Agentic Workflow (PAW)

A structured framework for using AI coding assistants as rigorous tutors, rather than simple code generators.

## Overview

As AI coding assistants become more capable, they introduce a significant risk for learners: the **illusion of competence**. When an AI generates perfectly formatted code and you copy-paste it into your project, it feels like you're learning. In reality, you are bypassing the active cognitive effort required to understand syntax, architecture, and debugging.

The purpose of PAW is to help beginners or those who have little practical experience in software development develop projects in a professional manner **right now** through the guidance of AI agents. PAW is not aimed at working professionals meeting deadlines.

The PAW framework inverts the typical AI-developer dynamic. It configures the AI agent to act as an uncompromising tutor. Under PAW, the agent teaches concepts, verifies your understanding through quizzes, and only presents code after you have proven that you comprehend the underlying principles.

## Getting Started

To use PAW, you do not need to install any external packages. The framework relies entirely on prompting your chosen AI coding assistant (such as those found in VS Code, Cursor, Windsurf, or Antigravity).

* **If you already have your development environment set up:** Read the [PAW Framework](docs/pedagogical_agentic_workflow_framework.md) to understand the rules, then skim the Beginner's Guide for specific AI prompting steps.
* **If you are a complete beginner:** Head directly to the **[PAW Beginner's Guide](docs/paw_beginners_guide.md)** for step-by-step instructions on setting up your IDE, managing costs, and starting your first project.
